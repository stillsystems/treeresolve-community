      Core Capabilities
      
Built for Performance and Precision

      
Traditional merge tools rely on line-based guessing. TreeResolve brings full compiler-grade understanding directly to your editor.

    


    

      

        
⚡

        
Concrete Syntax Tree Engine

        
Pre-compiled WebAssembly parsers parse AST nodes in background workers, performing mathematical set-difference reconciliations with 3-way deletion tracking.

      


      

        
🎨

        
Dynamic Bézier Ribbons

        
Hardware-accelerated HTML5 canvas ribbons link corresponding code blocks across Ours, Merged Result, and Theirs with proportional alignment scrolling.

      


      

        
🔒

        
Air-Gapped & Zero Data Egress

        
Your source code never leaves your local machine. No LLMs, no remote API calls, no token leakage. Complies with the strictest InfoSec policies.

      


      

        
🔍

        
Intra-Line Token Micro-Diffing

        
Off-thread LCS diffing visually distinguishes exact character and word substitutions within conflicting lines, highlighting additions and deletions in color.

      


      

        
📦

        
Semantic Lockfile Resolution

        
Automatically auto-merges non-breaking semver bumps and concurrent package additions in package-lock.json while aligning SHA-512 integrity hashes.

      


      

        
⚙️

        
Repo Policy Engine (.treeresolverc)

        
Check project-level glob policies directly into your Git repository to govern auto-merge rules and automatic staging across large engineering teams.

      FAQ
      
Answers Before You Install

      
Trial, privacy, language support, and how TreeResolve differs from AI merge tools.

    


    

      

        What happens after the 14-day reverse trial?
        

          TreeResolve automatically degrades to the free Community tier. Your editor is never locked —
          you keep the 3-pane merge canvas and can resolve conflicts manually. Upgrade to Pro anytime
          for unlimited deterministic AST auto-merge. No credit card is required to start the trial.
        

      


      

        Does my source code leave my machine?
        

          No. Parsing, AST analysis, and conflict resolution run locally. TreeResolve does not send
          source code, conflict hunks, or repository contents to LLMs or cloud merge services.
          See the Privacy Policy.
        

      


      

        What is the anonymous device fingerprint used for?
        

          To issue reverse trials and renew floating leases without accounts or passwords, TreeResolve
          may send an anonymized SHA-256 hash of platform:arch:machineId (truncated to 32 hex
          characters). No usernames, hostnames, or MAC addresses are included. Offline / air-gapped
          enterprise keys never contact the licensing endpoint for validation.
        

      


      

        Which languages get deterministic auto-merge?
        

          Dedicated AST normalizers cover TypeScript/JavaScript, Python, Go, Rust, Java, C#, JSON/JSONC,
          YAML, and npm lockfiles. All other languages still open in the 3-way visual canvas with a
          graceful line-based fallback. Language support expands over time — see the README matrix for details.
        

      


      

        How is this different from AI merge tools?
        

          TreeResolve is zero-AI and deterministic: the same inputs always produce the same merge result.
          There are no hallucinations, no prompt leakage, and no dependency on a remote model. If two
          changes are syntactically disjoint, they merge; true conflicts stay visible for you to decide.
        

      


      

        Do I need the VS Code extension, the CLI, or both?
        

          The extension gives you the interactive 3-way canvas inside VS Code. The standalone CLI
          (npx treeresolve) works as a Git mergetool and for headless / CI auto-resolution.
          Both share the same licensing model. Headless runs default to Community unless a Pro or
          Enterprise license is configured.
