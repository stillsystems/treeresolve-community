      Core Capabilities
      
Built for Performance and Precision

      
Traditional merge tools rely on line-based guessing. TreeResolve brings full compiler-grade understanding directly to your editor.

    


    

      

        
⚡

        
Concrete Syntax Tree Engine

        
Pre-compiled WebAssembly parsers parse AST nodes in background workers, performing mathematical set-difference reconciliations with 3-way deletion tracking.

      


      

        
🎨

        
Dynamic Bézier Ribbons

        
Hardware-accelerated HTML5 canvas ribbons link corresponding code blocks across Ours, Merged Result, and Theirs with proportional alignment scrolling.

      


      

        
🔒

        
Air-Gapped & Zero Data Egress

        
Your source code never leaves your local machine. No LLMs, no remote API calls, no token leakage. Complies with the strictest InfoSec policies.

      


      

        
🔍

        
Intra-Line Token Micro-Diffing

        
Off-thread LCS diffing visually distinguishes exact character and word substitutions within conflicting lines, highlighting additions and deletions in color.

      


      

        
📦

        
Semantic Lockfile Resolution

        
Automatically auto-merges non-breaking semver bumps and concurrent package additions in package-lock.json while aligning SHA-512 integrity hashes.

      


      

        
⚙️

        
Repo Policy Engine (.treeresolverc)

        
Check project-level glob policies directly into your Git repository to govern auto-merge rules and automatic staging across large engineering teams.

      

    

  


  
  

    

      

        Terminal Workflows
        
Standalone Git Mergetool Companion

        

          Prefer working in the terminal or running headless auto-resolution in CI/CD pipelines? TreeResolve includes a standalone CLI executable with zero dependencies.

        # 1. Configure Git global mergetool in one command

        npx treeresolve setup-git


        # 2. Batch auto-resolve all clean syntax conflicts

        npx treeresolve auto

        git mergetool -t treeresolve
